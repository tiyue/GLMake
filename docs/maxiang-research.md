- 文档编号：GLMAKE-RESEARCH-002
- 版本：1.0
- 日期：2026-08-06
- 方法：只读调研（桌面 1350×1315 视口，未登录、未创建/修改任何笔记）；DOM/几何/样式实测 + 弹层结构抽取 + 官网帮助页交叉核对。
- 对象版本：Web 1.8.0（About 模态实测）。
- 边界：不复制其品牌、图标字体、CSS 与文案；本报告仅提取布局概念、交互结构与功能清单，供 GLMake 独立实现。

## 1. 总体布局（实测几何）

| 区域 | 几何（1350 视口） | 样式实测 |
| --- | --- | --- |
| 编辑器 | x0 y0 w675 h1315（左半、**全高**） | 背景 `rgb(54,49,44)` 深棕；文字 `rgb(235,209,183)` 暖米；字体 "PT Sans" 16px/26.4px |
| 预览 | x675 **y50** w668（右半、顶部让出 50px） | 文字 `rgb(44,63,81)` 蓝灰；字体 Helvetica Neue/Arial/Hiragino Sans GB 16px；白底 |
| 工具栏 | 全宽、浮置、高约 50px | 背景 `rgb(228,235,241)` 浅蓝灰；按钮为图标按钮（icon 字体） |
| 状态 | 右下角 dropup「统计」 | 字符/Words/段落 三项 |

关键概念：**无常驻侧栏**；编辑器从顶到底占左半，工具栏浮于其上；预览独立让出工具栏高度。

## 3. 文档管理模态（Manage documents）

- 标题为**英文** "Manage documents"（界面中英混排事实）。
- 顶部操作组「Selection」：Select all / Unselect all / Move to folder / Delete（批量）。
- 「Create folder」按钮。
- 列表区：文档多选列表（未登录时为空）。
- 确认文案：删除时 "The following documents will be deleted locally:"；移动时 "Please choose a destination folder:"；按钮 Cancel/OK/Close。

## 4. 系统菜单与设置

- 系统菜单（Ctrl+M / 右上个人按钮）：设置、帮助、关于、登录/退出等。
- 设置项（帮助页与 charter 基线交叉）：编辑器选择、代码高亮主题、字体、字号、自定义渲染 CSS、Vim/Emacs 键盘模式、自动同步开关。
- 设置模态内含「Import documents and settings」确认："This will delete all existing local documents. Are you sure?"（Cancel/OK）。
- About：版本 1.8.0、更新日志、反馈（邮箱/微博）。

## 5. 分享模态（中文）

- 标题「分享链接」；说明「公开链接可以让你轻松分享笔记给其他人。」
- 按钮：停止分享 / 确定。链接只读、可停止。

## 6. 冲突与同步提示（原文）

- 文件冲突：「检测到本地有尚未同步的修改，将打开本地版本。请仔细对比本地与 Evernote 中的内容，以决定同步或删除本地版本。操作前请做好备份。」附注：确认本地过时时「在右侧菜单中点击删除文档，然后在 Evernote 中找到笔记，点右上角的红标跳回到马克飞象」。
- 版本冲突：「检测到这篇笔记在 Evernote 中有较新的版本……」同样引导对比与备份。
- 自动同步提示：「当前笔记已经有一段时间未同步到 Evernote，是否立即同步？」确定/取消。
- 概念要点：**冲突不自动覆盖**，打开本地版并引导人工对比；删除本地副本是"采用云端"的显式动作。

## 7. 帮助模态（语法 + 快捷键，实测全文）

语法表：强调 `*斜体*` `**粗体**`（Ctrl I/B）；链接（Ctrl L）；图片（Ctrl G）；笔记本 `@(笔记本)[标签1,标签2,标签3]`；标题（setext 与 `##`，Ctrl 1~5）；有序/无序/复选框列表；引用；行内代码与代码块（Ctrl K）；LaTeX 行内 `$…$` 与块级 `$$…$$`；表格（Ctrl Alt T）。

快捷键表：文档管理 Ctrl O；帮助 Ctrl /；最大化编辑器 Ctrl Enter；预览文档 Ctrl Alt Enter；同步文档 Ctrl S；创建文档 Ctrl Alt N；系统菜单 Ctrl M。

图片管道指令：`![@描述 | left | 300x0](a.jpg)` —— `@描述` 显示在图片下方；left/right/center 对齐；`宽x高`，0 为自适应。

## 8. 窄屏与移动端（官网观察，charter §3.3 交叉）

- 预览收起，编辑区成为主视图；顶部仅留少量图标；正文单栏滚动。
- 存在移动端 Web 降级，但细节不足以推断断点。

## 9. 中英混排与文案风格事实

- 核心用户文案为中文（同步、分享、冲突、帮助）；文档管理与统计等模块残留英文（Manage documents / Select all / Words）。
- 按钮几乎全为**纯图标 + title 提示**，信息密度高、 chrome 极薄。
