# GLMake 隐私说明（简体中文）

- 版本：1.0
- 适用：GLMake 全部公开部署与自托管实例

## 我们如何对待你的数据

1. GLMake 设计为**单用户自托管**工具。实例只服务部署它的所有者；不开放公共注册，
   不采集任何其他用户的数据。
2. **没有**广告、用户行为追踪、第三方统计分析或遥测。服务器只记录登录、安全和故障
   排查所需的最少日志；日志不包含笔记正文、附件内容、完整会话令牌或密码。
3. 正文、附件、笔记本、标签、版本历史与搜索索引保存在所有者自己的服务器上。
4. 浏览器在本地（IndexedDB）保存编辑副本，用于离线续编与冷启动恢复；清除站点数据
   会删除本地副本，请定期使用"全量导出"。

## 必须知晓的风险（默认部署形态）

- 默认部署允许直接通过**公网 HTTP** 使用：登录密码、会话、正文与附件在传输路径上
  可能被截获或篡改；服务器上的静态数据与全量导出包**不加密**。
- 因此 GLMake 只适合存放所有者可以接受公开泄露的非重要文件；**不要**把它当作敏感
  资料的存储或传输工具。
- 所有者应使用**仅供 GLMake 的独立密码**，并把一次性恢复码抄存在服务器之外。

## 分享链接

- 分享链接为只读、默认不过期、可随时撤销；分享页面带有禁止搜索引擎收录的指令。
- 全量导出包不包含任何有效分享凭据；迁移后旧链接全部失效。

## 你的权利

- 随时通过"全量导出"取走全部数据（未加密 ZIP，含正文与附件）。
- 随时永久删除文档；永久删除后数据不再出现在活动入口与之后的导出包中。
- 自行审查、修改、重新构建本软件（Apache-2.0）。
